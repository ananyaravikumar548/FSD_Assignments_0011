# RV University - Department of Computer Applications (BCA) Frontend

A modern, fast, and responsive frontend portal for the **Department of Computer Applications (BCA)** at **RV University, Bengaluru**.

---

## 🚀 Features

- **Header & Navigation**: Sticky navbar with RV University brand mark, Department logo, quick "Apply Now" CTA, and active section scrollspy.
- **Hero Banner**: High-impact banner featuring the Department headline, student spotlight visual, interactive slide navigation, and floating highlight cards deck.
- **About Department**: 80-year RSST legacy, core learning pillars, and key statistics bar.
- **HOD's Desk**: Leadership message from Dr. Manish Kumar, Head of Department & Professor, with credentials, quote callout, and office hours.
- **BCA Programs (NEP 2020)**: 3-Year BCA & 4-Year BCA (Honours) specializations (Full Stack, AI & Data Science, Cloud & Cybersecurity, UI/UX Design) with interactive semester curriculum modals.
- **Faculty Directory**: Real-time search filter by professor name or technology specialization, with bio and publication modals.
- **Laboratories & Infrastructure**: Interactive switcher for the 5 specialized computing centers (Full Stack Studio, AI GPU Cluster, Cloud Sandbox, IoT Hub, HCI Design Lab).
- **Research & Innovation**: Student capstone innovations (CampusNav, Smart Attendance, SecureChain) and research metrics.
- **Placements Hub**: ₹24.5 LPA highest CTC, placement statistics, marquee recruiters grid, and alumni testimonials.
- **Events & Hackathons**: RV Hacks 2026, ByteQuest TechFest, and workshop archives with registration triggers.
- **Downloads Center**: 1-click access to official NEP syllabus PDFs, academic calendars, and project handbooks.
- **Admission Inquiry & FAQs**: Responsive inquiry form with validation, campus directions, and interactive FAQ accordion.
- **Mobile Responsive & Accessible**: Clean mobile drawer, fluid typography, and sub-100ms transitions.

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

- **Frontend Client**: [http://localhost:3000](http://localhost:3000)
- **Backend API**: [http://localhost:5000](http://localhost:5000)

Or run just the client:
```bash
npm --workspace client start
```

### 3. Production Build
```bash
npm run build
```
